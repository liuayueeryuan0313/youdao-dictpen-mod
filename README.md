## 使用

仅面向 RK3562 Melon / Melon Pro、固件 4.3.5、已有 root ADB 的设备。电脑需先安装 Python 3 和 Android platform-tools，保证 python3（Windows 为 python）和 adb 在 PATH 内；包内不含这些工具，也不负责开启 root 或首次调试授权。

1. 解压整个文件夹，连接一台笔，打开 USB ADB，保持设备空闲且供电充足。
2. macOS 双击「检查.command」，Windows 双击「检查.bat」。检查成功会显示 PREFLIGHT_OK。此步骤仅上传暂存文件并检查，不改应用或系统文件，不重启。
3. 双击「安装.command」或「安装.bat」。脚本在目标设备本地建立原状备份后写入补丁，成功后自动重启。安装过程中不要操作笔、切换调试设置或断开连接。
4. 撤销本次安装：连接同一台设备，双击「恢复.command」或「恢复.bat」，成功后自动重启。

Linux 或命令行：在本目录运行 `python3 manage.py check`、`python3 manage.py install`、`python3 manage.py restore`。

设备型号、固件、所需应用目录、可用空间和已存在目标文件的已知哈希均须匹配。未知版本会停止；不能通过跳过检查用于其他固件。再次安装前须先恢复。检查通过仅说明这些检查条件满足，不等于干净设备端到端安装已验证。

## 隐私与目标机配置

本包不附来源设备的序列号、账号、Cookie、Wi-Fi 配置、头像、聊天、照片、下载文件、日志、数据库、SSH 私钥或原密码。仅复制经过检查的应用/系统代码和资源，不携带 /userdata 用户数据和整份 env.json/cfg.json。

SFTP 使用 `files` 账号，安装时在目标机生成独立的 16 位随机密码；该账号按原魔改方案具有根目录访问权限。密码由目标机设置菜单展示，包内仅有占位模板。已有目标 SSH 主机密钥保留，没有则在目标生成。新目标默认关闭 SFTP、无线 ADB 和日志上传，USB ADB 默认开启；目标已有偏好会保留，可能覆盖这些默认值。遇到非本魔改管理的同名 files 账号会回滚停止，不强行接管。

目标原有账号文件、配置及将被覆盖的文件仅备份在该目标设备 `/userdisk/mod-backups/unified-mod-v1/`，不回传电脑、不进分发包。这份设备侧备份可能包含该目标自己的敏感信息，不应分享。勿删除备份后再要求恢复。

## 恢复的含义

恢复回到「运行本包安装之前」的目标机状态，并卸载本次新注册的文件管理/相机；原先就存在的应用不会被卸载。用户照片与其他正常文件不属于删除范围。若在已经魔改的笔上安装，再恢复，返回的仍是安装前的魔改状态，**不等于恢复出厂原版**。

cfg.json 与 env.json 按本次变更的字段恢复，尽量保留后续无关设置及被用户另行修改的值。魔改专用配置、认证文件按安装前备份恢复。程序文件或系统账号在安装后有变化，或备份校验失败时，恢复会停止，避免直接覆盖其他修改；不要删除 state 或篡改清单来强制继续。

普通命令失败触发自动回滚；突然断电、USB 丢失或强制结束进程无法保证自动恢复。失败后查看终端输出，保持 ADB 可用。必要时先运行 `adb shell "sh /userdisk/mod-backups/unified-mod-v1/restore.sh --failed"` 使用目标本机备份恢复（跳过安装后文件一致性检查，仍校验备份），确认成功后再手动重启。这是异常恢复入口，不要用于覆盖另一次更新。
